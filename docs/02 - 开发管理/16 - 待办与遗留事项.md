## 四、已知的技术债（不影响功能，但该记）

### D1 既有测试不支持 `-count>1`

`runtime/component` 的测试用 `component.Register`（全局注册），`go test -count=2` 会 panic「重复注册」。
**不是本轮引入**，但让「连跑多次查 flake」这个手段在部分包上不可用。

- **处置建议**：加 `testing.TestMain` 或把注册改成幂等（同名注册返回已有组件）。
- **量**：小。**风险**：低。

### D2 `Turn` 点位的 `Resumed` 判定依赖 `ag.Pending()`

`a.ag.Pending()` 表示「打开时还有未完成回合」。如果将来出现「未完成回合但 Pending 为 false」的路径，
`Resumed` 会失真。目前只有崩溃恢复会走到，无实际问题。

- **处置建议**：加注释说明这个前提，或改成显式传参。
- **量**：小。**风险**：低。
