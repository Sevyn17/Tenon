# 接前端

应用跑起来后，`App.API()` 就是完整的应用协议服务端：列会话、发消息、流式输出、回答确认。交给一个传输层，前端就能连上。完整代码见 `examples/web-server/main.go`。

## 1. 装配

```go
app, err := tenon.New(tenon.Default(), tenon.WithStore(db), tenon.WithWorkdir(dir),
    tenon.WithProtocolUI(), // 确认、提问交给连上来的前端回答
    tenon.WithOpenAI(baseURL, model, tenon.Env("TENON_API_KEY")))
if err := app.Start(ctx); err != nil { … }
api := app.API() // Start 之前、Close 之后是 nil
```

不加 `WithProtocolUI` 时，需要确认的调用立即拒绝，前端看不到确认卡。

## 2. 网页：`transport/web`

```go
import web "github.com/Sevyn17/tenon/transport/web"
import webui "github.com/Sevyn17/tenon/web"

token, _ := web.NewToken()
srv := web.New(web.Config{
    API:    app.API(),
    Token:  token,                    // 浏览器第一次用 ?token= 打开，之后走 cookie
    Hosts:  web.LoopbackHosts(port),  // 允许的 Host 头，挡 DNS 重绑定
    Static: webui.Dist(),             // 框架自带的工作台；不要界面时留空
})
http.Serve(ln, srv)
```

- 只监听回环地址时用 `LoopbackHosts`；对外提供服务时把 `Hosts` 写成真实域名，`TLS: true`（Origin 要求 https，cookie 加 Secure）。
- 令牌是唯一的鉴权。要让别的进程拿到地址，用 `web.WriteTokenFile(path, url)` 写进只本人可读的文件，返回的函数在退出时删掉它。
- 多租户、按请求鉴权现在没有（见 [07 SDK 接口](<../框架设计/07 - SDK 接口.md>) 7.6）。

跑示例：

```bash
cd web && pnpm install && pnpm build && cd ..   # 生成 web/dist，Go 编译时嵌进去
TENON_BASE_URL=https://api.deepseek.com/v1 TENON_MODEL=deepseek-chat TENON_API_KEY=… go run ./examples/web-server -dir <工作目录>
```

终端打印带 `?token=` 的地址，用浏览器打开。

## 3. 桌面壳：`transport/bind`

```go
svc := bind.NewService(app.API(), func(name string, data any) { /* 推给前端，如壳的事件接口 */ })
```

把 `svc` 绑给 Wails 之类的壳，前端按同一套协议调用；事件经 `emit` 推给前端（事件名 `bind.EventName`）。

## 4. 前端：`@tenon/web`

`web/` 是框架的前端，分四层，按需要选到哪一层：

| 想要 | 用 |
|---|---|
| 完整工作台 | `createShell({brand, contributions})`（`@tenon/web/shell`） |
| 嵌一个对话框 | `<TenonConversation session="…" />`（`@tenon/web/shell/embed`） |
| 自己的组件库 | 协议客户端 + hooks（`@tenon/web/client`、`/client/react`） |
| 别的框架（Vue、原生、移动端） | 只用协议客户端 `createClient()`，或按 [06 应用协议契约](<../06 - 应用协议契约.md>) 自己写 |

`@tenon/web` 还没发 npm，在自己的前端里用 `link:` 引用：

```json
{ "dependencies": { "@tenon/web": "link:../path/to/tenon/web" } }
```

`vite.config.ts` 里加 `resolve: { dedupe: ["react", "react-dom"] }`，只留一份 React。分层、贡献包、插槽见 `web/README.md`。

## 5. 不用 Go 写前端的服务端

协议是 JSON 帧，走 WebSocket（`transport/web`）或绑定调用（`transport/bind`）。命令、事件、帧的结构在 `tenon/appapi/wire`，语义在 06 应用协议契约。前端只依赖这两样，服务端内部（`tenon/appapi`）可能变。
