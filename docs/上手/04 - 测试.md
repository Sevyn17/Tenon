# 测试

`tenon/tenontest` 用脚本模型代替真实模型：按顺序回放写好的回复，不联网、不要密钥，结果每次一样。

## 1. 脚本模型

```go
app := tenontest.New(t, tenon.WithTools(lookup),
    tenontest.Model(
        tenontest.Reply("我查一下").CallTool("order_query", `{"id":"A1"}`), // 第 1 次调模型
        tenontest.Reply("A1 已发货")))                                      // 第 2 次：工具结果之后
r, err := app.Ask(ctx, "", "A1 到哪了", nil)
app.AssertToolCalled("order_query")
```

- 每一步对应一次模型调用。带 `CallTool` 的一步发起工具调用，框架真的执行工具，再调下一步；一步里可以 `CallTool` 多次。
- 脚本不看请求内容，只按次数走。调用次数超过步数时这次模型调用失败（`script_exhausted`），说明多调了一次。
- 一个 `Model(...)` 的计数在整个应用里共享：多轮、多会话的步骤按实际调用顺序连着写。

## 2. 测试应用

`tenontest.New(t, opts...)` 等于：

```go
tenon.New(tenon.Default(), tenon.WithStore(memstore), tenon.WithWorkdir(t.TempDir()), tenontest.Model(), opts...)
```

再 `Start`，测试结束时 `Close`。`opts` 在后面，自己的 `tenontest.Model(...)` 覆盖缺省的空脚本。装配或启动失败直接 `t.Fatal`。

- 两种存储都要过：`for _, b := range tenontest.Stores() { t.Run(b.Name, func(t *testing.T) { app := tenontest.NewOn(t, b.Open(t), …) }) }`，内存和 SQLite 各跑一遍。
- `app` 嵌着 `*tenon.App`，`NewSession`、`History`、`Session` 都能用。`AssertToolCalled` 只看经 `app.Ask` 开的会话。

## 3. 看结果

除了 `Reply.Text`，常用的有两处。

工具结果在历史里：

```go
h, _ := app.History(ctx, r.SessionID)
for _, e := range h {
    if tr := e.Item.ToolResult; tr != nil {
        // tr.Status.State 是 "ok" / "error" / "cancelled"；tr.Output 是内容片段
    }
}
```

事件流里按顺序看：

```go
for ev := range s.Stream(ctx, "退掉 A1") {
    switch ev.Kind {
    case tenon.EventConfirm:
        ev.Approve(true)
    case tenon.EventToolResult:
        // ev.Text、ev.Failed
    }
}
```

## 4. 确认

`tenontest.New` 没有界面：`Ask` / `Send` 遇到要确认的调用立即拒绝，模型收到"用户拒绝"，接着走脚本的下一步。要测确认，用 `Stream` 回答 `EventConfirm`。

要让 `shell` 这类内置工具也要确认，把权限档位定死：

```go
tenon.WithConfig("permission", map[string]any{"force_mode": "ask"})
```

## 5. 示例程序怎么测

示例把逻辑写成 `run(ctx, w, …, model tenon.Option)`：`main` 传 `WithOpenAI(...)`，`main_test.go` 传 `tenontest.Model(...)`，断言写到 `w` 的输出。`examples/hello`、`tools`、`component` 都是这样，`go test ./...` 会跑它们。

根包的 `Example` 函数（`example_test.go`）也用脚本模型，`go test` 核对输出。
