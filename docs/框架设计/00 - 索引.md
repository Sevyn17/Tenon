## 定位

框架是一个智能体框架，类比 Web 世界的 FastAPI / Django：

- **开发体验**学 FastAPI / Django：类型声明生成校验和文档、组件自带数据和配置、应用用代码装配、约定优于配置、自带测试工具。
- **运行时**学 Erlang/OTP 和 Temporal：会话 + 信箱 + 监督树，每步落检查点、崩溃后从断点接着跑。

| B11 | 多人会话由内核支持：信封 `from` 是一等字段，权限和记账按本轮触发者算；成员表、邀请、角色由成员组件管。多智能体群聊不进内核，用小组资源加各自的会话（02、08） | 2026-11-01 |
| B12 | 智能体没有记忆。内核只有会话上下文，天然隔离；长期记忆是组件数据。跨会话读取只走记忆组件、共享资源、读会话历史的工具三条路，都过守卫（02 2.5） | 2026-11-01 |
| B13 | 组件全局单例，每次调用通过 `*Ctx` 拿到租户、会话、触发者；有会话状态的资源用 `SessionLocal` 句柄。租户、用户是一等字段，不放 `meta`（04 4.4、07 7.3） | 2026-11-01 |
| B14 | 框架按"核心 + 模块"组织：核心不可替换；模块是 SDK 里的 Go 包，可选用、不用或重写，`tenon.Default` 是预设组合。标准模块只能通过公开扩展点实现，缺能力就补扩展点，不在内核开特例（01 1.2、04 4.1） | 2026-11-01 |
