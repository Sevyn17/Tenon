# 十分钟：带工具的智能体

照着做完，你会有一个接真实模型、能调用自己写的工具的程序。应用代码只 import `github.com/Sevyn17/tenon`（包名 `tenon`）；存储实现按需另引一个包（见第 4 节）。先 `go get github.com/Sevyn17/tenon`。完整代码见 `examples/chat/main.go`。

## 1. 写一个工具

参数用结构体描述，JSON Schema 按字段生成：

```go
type OrderArgs struct {
    ID string `json:"id" desc:"订单号"`
}

lookup := tenon.Func("order_query", "按订单号查订单状态",
    func(ctx context.Context, a OrderArgs) (any, error) {
        return map[string]string{"id": a.ID, "status": "已发货"}, nil
    })
```

字段规则：

- 名字取 `json` tag；`desc` 写说明，`enum:"a,b"` 写可选值。
- 指针字段或带 `omitempty` 的字段可选，其余必填。
- 返回值：`string` 原样交给模型，其余编成 JSON。返回错误时这次调用失败，错误信息交给模型，回合继续。

要自己写 schema 用 `tenon.Raw(name, desc, schema, fn)`。

工具缺省是只读的，不经权限确认。会改东西的标出来，交给权限组件按档位判定：

```go
refund := tenon.Func("order_refund", "退款", doRefund).Dangerous() // 或 .Writes()
```

其他修饰：`.Timeout(d)`、`.Serial()`（不和同一步的其他调用并行）。

工具里要知道是哪个会话在调：`ci, _ := tenon.CallInfoFrom(ctx)`，有 `Session`、`Agent`、`User`、`Tenant`、`Meta`。

## 2. 接模型

```go
tenon.WithOpenAI("https://api.deepseek.com/v1", "deepseek-chat", tenon.Env("DEEPSEEK_API_KEY"))
tenon.WithAnthropic("claude-sonnet-4-5", tenon.Env("ANTHROPIC_API_KEY"))
tenon.WithModel("deepseek-chat")          // 内置目录里的模型，密钥按目录读环境变量
tenon.WithModelCatalog("models.toml")     // 自己的目录：多个提供方、别名、降级
```

密钥只以引用出现（`tenon.Env("NAME")` 即 `env:NAME`），不收明文。接自己的密钥库用 `tenon.WithSecrets(func(ref string) (string, error) {…})`。

## 3. 定义智能体（可选）

```go
tenon.WithAgent(tenon.Agent{
    Name:   "support",
    Prompt: "你是售后客服，查订单要用工具。",
    Tools:  []string{"order_query"}, // 空 = 不限
})
```

也可以放目录：`tenon.WithAgents(tenon.Dir("agents"))`，每个子目录一个 `agent.toml`。

不给名字时这样选：

| 情况 | 用哪个 |
|---|---|
| `WithDefaultAgent("x")` 指定了 | x |
| 只有一个定义 | 它 |
| 一个定义都没有 | 内置 `default`：中性提示词，只带 `WithTools` 的工具和只读的内置工具 |
| 多个定义 | 报错，列出可选名字 |

内置 `default` 不带跑命令、写文件的工具。要用它们，写一个定义把工具列出来。

## 4. 装起来，问一句

```go
app, err := tenon.New(tenon.Default(),
    tenon.WithStore(memstore.MemoryStore()), // import "github.com/Sevyn17/tenon/runtime/store/memstore"；落盘用 sqlite.SQLiteStore(ctx, path)
    tenon.WithTools(lookup),
    tenon.WithOpenAI(baseURL, model, tenon.Env("TENON_API_KEY")))
if err != nil { log.Fatal(err) }
if err := app.Start(ctx); err != nil { log.Fatal(err) }
defer app.Close(ctx)

r, err := app.Ask(ctx, "", "我的订单 A1 到哪了？", nil)
fmt.Println(r.Text)
```

`Ask` 每次新开一个会话。接着聊见下一篇。

## 5. 跑

```bash
TENON_BASE_URL=https://api.deepseek.com/v1 TENON_MODEL=deepseek-chat TENON_API_KEY=… go run ./examples/chat
```

## 不接模型也能测

`tenon/tenontest` 有脚本模型，按顺序回放写好的回复：

```go
app := tenontest.New(t, tenon.WithTools(lookup),
    tenontest.Model(
        tenontest.Reply("查一下").CallTool("order_query", `{"id":"A1"}`),
        tenontest.Reply("A1 已发货")))
r, _ := app.Ask(ctx, "", "A1 到哪了", nil)
```
