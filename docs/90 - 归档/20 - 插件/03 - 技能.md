# 技能（Agent Skills）— 5.8

## 参考
- pi-mono `coding-agent/src/core/skills.ts`：name ≤64、`^[a-z0-9-]+$`、无首尾/连续连字符；description 必填 ≤1024；name 缺省取父目录名；`disable-model-invocation`；目录提示 "Load a skill's file when the task matches its description"。
- DSH `dsh-skill` / `dsh-skill-filesystem` / `dsh-tool-skill`：多来源注册表按名排序、同名先到先得；只认顶层 `<name>/SKILL.md` 与 `<name>.md`，不递归；目录描述截 500；`skill {name}` 工具返回 `<skill_content>`，装载时重新校验名字；modelInvocable / userInvocable 策略。
- Codex `core/src/skills.rs`、opencode `core/src/skill.ts`：同类发现 + 按需装载。

## 结论
- 格式：Agent Skills 标准 frontmatter（name、description 必填；`disable-model-invocation: true` → 模型不可见）。
- 根（先列优先，同名先到先得并告警）：工作目录与项目根下 `.ybase/skills`、`.agents/skills`，再 `~/.ybase/skills`（或 `$YBASE_HOME/skills`）。只扫顶层，跳过点目录与 node_modules。
- 目录：会话创建时渲染为系统块（Source `skills`），之后不变，保证前缀缓存稳定；每条描述截 500 字符，总预算 8KiB，超出的条目只列名字。
- 装载：`skill {name}` 工具（Risk Read）重新读盘并校验名字未变，正文上限 64KiB，返回 `<skill_content>` 并给出技能目录（相对路径据此解析）。结果作为普通工具历史保留。
- 推迟：目录热更新（DSH 追加替换目录）、用户 `/name` 显式调用、远程/插件内嵌来源。P0 新增技能需新会话生效。
