# M7 试用指南

ybase 目前只有终端界面（一个命令行对话程序）。在 PowerShell 里启动，像聊天一样打字即可。

## 启动

```powershell
& "C:\Users\qsevn\Desktop\Code\Agent\YBase\kernel\scripts\ybase.ps1" -Dir D:\你的项目
```

- 每次启动会先重新编译（第一次约 30 秒），可执行文件放在 `%LOCALAPPDATA%\ybase\ybase.exe`。
- key 读自 `kernel/.env`，默认模型 `deepseek-flash`（chat completions）。
- 常用参数：
  - `-Session 名字`：会话名，同名再次启动就是续聊（存在 `<项目>\.ybase\state.db`）。
  - `-Model deepseek-v4-pro`，或 `-Model deepseek-responses/deepseek-flash`、`-Model deepseek-anthropic/deepseek-flash` 换协议。
  - `-mode 档位`：read-only（仅可查看）/ ask（每次询问）/ workspace（缺省，工作区内改文件、跑命令不问；联网、MCP 询问）/ full（完全权限），或自定义档位名（`~/.ybase/modes/<名>.toml`，用 `ybase mode copy workspace 我的` 生成模板）；会话里也可用 `/mode` 切换，档位随会话保存；`/mode show` 列出每个权限项的取值和来源。
  - `-yes`：等同 `-mode full`，什么都不问。
  - 沙箱插件缺省关闭，此时 shell 命令只按档位判定，没有系统层限制。要开沙箱，在 `~/.ybase/profile.toml` 写 `[[plugin]]` / `name = "sandbox"` / `enabled = true`；开启后沙箱级别随档位，`-sandbox 模式` 可固定（read-only / workspace-write / danger-full-access）。
  - 确认提示里输入 `y` 本次允许，`a` 本次会话内都允许，其他为拒绝。

建议先拿一个**有 git 的项目**试，出问题可以 `git checkout` 回去。

## 对话里能用的操作

| 操作 | 作用 |
| --- | --- |
| 回车 | 发送 |
| 回合进行中打字回车 | 插话，模型下一步就能看到 |
| Ctrl+C | 取消当前回合 |
| `/stats` | 用量、缓存命中率、上下文组成 |
| `/mode [档位]` | 查看或切换权限档位（随时可用，重启后仍生效） |
| `/compact` | 手动压缩历史 |
| `/rewind [n]` | 退回 n 个回合 |
| `/fork 名字` | 从当前位置分叉一个新会话并切过去 |
| `/exit` | 退出 |

## 建议测的场景

每项做完在下面的反馈表里记一行即可，不需要每项都测。

1. **读代码答问**：问“X 功能在哪实现、怎么工作的”。看它会不会用 grep/glob/read_file 找，答案对不对。
2. **小改动**：让它修一个小 bug 或加一个小功能，并跑测试。看 edit 是否改对、有没有乱改别处。
3. **多步任务**：比如“加一个参数，更新文档和测试”。看它会不会列计划（📋），中途能否被插话纠正。
4. **确认流程**：用 `/mode ask` 或让它写工作区外的文件，看确认提示是否清楚、`a` 之后同类操作是否不再问、拒绝后它会不会换做法。
5. **中断与续跑**：回合中按 Ctrl+C；或直接关掉窗口，再用同一个 `-Session` 启动，看是否接着上次的状态。
6. **长会话**：连续聊很多轮，看 `/stats` 的缓存命中率，以及上下文变大后是否自动压缩、压缩后是否还记得目标。
7. **技能 / AGENTS.md**：项目里有 `AGENTS.md` 时看它是否遵守；`.ybase/skills/<名字>/SKILL.md` 放一个技能看它会不会按需加载。
8. **MCP**：`<项目>\.ybase\mcp.toml` 配一个 MCP server（格式见 `kernel/docs/20 - 插件/13 - MCP 客户端.md`）。
9. **子智能体 / 工作组**：让它“派一个子智能体去做 X”或“开两个成员分别做 X、Y”。

## 已知限制

- 没有图形界面，没有 Markdown 渲染，长输出直接滚屏。
- 只能在一个终端里看一个会话；子智能体/成员的输出不单独显示。
- shell 每次是新进程，`cd`、环境变量不会保留到下一次调用。
- 沙箱缺省关闭；开启后只限写、不限读和联网，且只在 Windows 上生效。node 类程序在沙箱里起子进程会报 `spawn EPERM`，遇到时用 `-mode full` 或关掉沙箱。
- 档位切换会改变发给模型的工具列表，切换后那一次请求的缓存命中会掉下来，属正常。
