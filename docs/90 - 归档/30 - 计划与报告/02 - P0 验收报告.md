## 试用中发现并已修的问题

1. 被 Guard 短路的写工具报"store: 工具记录状态不符"，回合失败（toolhub/exec.go）。
2. 外层 redact 包着 permission 时，确认请求被误判为 Transform 违规，ask 档所有写工具失败（toolhub/exec.go chain）。
3. 沙箱给工作区打 Low 标签，工作区内编出的 ybase.exe 以 Low 运行、无法建 .ybase；沙箱改为写受限令牌 + 能力 SID，并提供 `ybase sandbox-reset` 清除旧标签。
4. 沙箱内 `go test` 写不了用户级 GOCACHE；改为每个工作区专用缓存目录。

另外按试用反馈做了权限改版（五档、`工具(模式)` 规则、"本次会话内都允许"、`/mode` 持久化）。

- npm / pip / cargo 等用户级缓存在沙箱内同样不可写，未处理。
- 工作组没有真实模型验收，只有单测。
- （已解决，2026-10-31 薄内核改造）tools-builtin、model 包与 agent 旧执行路径已删除。
