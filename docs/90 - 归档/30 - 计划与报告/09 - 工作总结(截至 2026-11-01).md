## 一、项目现状一句话

`kernel/` 是一个 Go 写的智能体内核（module `ybase-kernel`，go 1.26），薄内核 + 内置插件结构，已经能在终端（CLI）、Wails 桌面端、本机网页三种外壳里跑，真机模型用 DeepSeek（chat / Responses / Anthropic 三种协议都通过冒烟）。

## 二、目录结构

| 位置 | 内容 |
|---|---|
| `kernel/core/` | 内核：session（会话内核）、reqlog、toolhub（工具管理器，含权限项注册表）、modelhub、host（会话宿主）、agent、bus、store（sqlite）、plugin（插件管理器）、runtime（装配点位）、appapi（应用接口层）、pkgs（插件包） |
| `kernel/plugins/<组>/<名>/` | 内置插件，每个插件一个 `plugin.go`；插件之间不得互相 import（`core/runtime/deps_test.go` 检查） |
| `kernel/apps/ybase` | CLI 程序 |
| `kernel/apps/desktop` | Wails v3.0.0 桌面端 |
| `kernel/apps/server` | 本机网页服务 `ybase-server` |
| `kernel/apps/internal/boot` | 三个程序共用的装配代码 |
| `kernel/web` | 共享前端（React 19 + TS + Vite），构建产物 `dist/` 由 `web/embed.go` 嵌入 |
| `kernel/scripts` | 验收与试用脚本（`ybase.ps1`、`accept_perm.sh`、`accept_p0.sh`、`smoke_protocols.sh` 等） |
| `kernel/docs` | 文档，命名「编号 - 中文名」，见第六节 |

内置插件（22 个）缺省开：store-sqlite、models、三个模型适配器、compact-basic、instructions、prompt、permission、fs、shell、ask-user。缺省关：redact、skills、sandbox、web、todo、mcp、codemode、hooks、subagent、workgroup。

### 工具权限（三轮，完成）
最终形态见 [06 - 工具权限设计方案](<06 - 工具权限设计方案.md>) 第九、十节，插件文档 [05 - 权限](<../20 - 插件/05 - 权限.md>)：
- **权限项注册表**：每个插件声明自己的权限项（`toolhub.Item`：switch / match / level 三种类型，类别九选一，各内置档位建议值），工具只引用项 id。未声明项的工具一律询问；不需授权的工具（todo、ask_user）显式 `NoAuth`。
- **档位**：内置 read-only / ask / workspace（缺省）/ full，**由插件建议值生成**，受封顶表 `plugins/security/permission/caps.go`（4 档位 × 9 类别）约束，越顶拒绝启动（`apps/ybase/items_test.go` 汇总检查）。自定义档位放 `~/.ybase/modes/<名>.toml` 或受信项目 `.ybase/modes/`，只认 `name`/`base`/`description`/`[items]`；可比基础档位更宽，但名字处处带放宽清单；项目档位放宽首次需 `/mode <名> -confirm`，记入 trust.toml。
- **判定**：公共 deny/ask → 会话临时层 allow → 档位取值 → 回落建议值 → 询问；任一项 deny 即拒、任一项 ask 即问。取值 deny 的工具不进模型工具列表。
- **公共规则** `permissions.toml` 只认 `mode`/`deny`/`ask`，写 allow 直接启动报错。
- **两层控制**：工具参数是闭集，shell 命令是开集；启动器类命令（sh、node、python、npm、make 等，见 `plugins/tools/shell/cmd.go` 的 `launchers`）永不被「本会话内都允许」生成的前缀规则放行。
- 删掉了全部旧兼容（[effects]/[tools]/[sandbox] 段、auto/custom 迁移、`工具[子串]` 写法、EffectOf 按 Risk 推断、缺省闸门）。
- 命令：`-mode`、`/mode [名]`、`/mode show`、`/mode copy`、`ybase mode list|show|copy`。
- 验收：`kernel/scripts/accept_perm.sh` 5/5 通过（DeepSeek）。

## 五、怎么跑

- CLI：`kernel/scripts/ybase.ps1 -Dir D:\项目 -Session 名字`（读 `kernel/.env` 的 DeepSeek key，exe 放 `%LOCALAPPDATA%\ybase\`）。试用指南 [03 - M7 试用指南](<03 - M7 试用指南.md>)。
- 桌面端：`cd kernel\web; pnpm install; pnpm build`，再 `go build -o $env:LOCALAPPDATA\ybase\ybase-desktop.exe ./apps/desktop`，运行时加 `-dir D:\项目 -trust-project`。
- 网页：`cd kernel; go run ./apps/server -dir D:\项目`，打开终端打印的带令牌地址。
- 新克隆仓库要先构建 `kernel/web/dist`，否则 `go build ./...` 失败。
